# data

本目录存放**已经复制进来的 Excel 文件**（不是目录联接、不是快捷方式）。

| 文件 | 用途 |
|------|------|
| `附件1.xlsx` | 问题1：一日分时电价、负荷、光伏 |
| `附件2.xlsx` | 问题2/3/4：365 天负荷与光伏实测 |
| `附件3.xlsx` | 问题3/4-3：每日 0/6/12/18 点发布的未来 24 h 整点光伏预报 |
| `附件4.xlsx` | 问题4：365×144 实时电价 |
| `result1.xlsx` | 附件5 填表模板，问题1 结果 |
| `result2.xlsx` | 附件5 填表模板，问题2 结果（2–12 月） |
| `result3.xlsx` | 附件5 填表模板，问题3 结果 |
| `result4-2.xlsx` | 附件5 填表模板，问题4 按问题2 框架 |
| `result4-3.xlsx` | 附件5 填表模板，问题4 按问题3 框架 |

程序通过 `src/common/paths.py` 的 `find_xlsx("附件1")` 等按文件名读取本目录。
